# Pre-Entrega: Backend con Node.js

Proyecto de pre-entrega desarrollado para el curso de **Backend con Node.js** de **Talento Tech**. 

El objetivo principal es construir una herramienta funcional para gestionar el catálogo de productos de una tienda en línea directamente desde la terminal, aplicando conceptos avanzados de manejo de estructuras, APIs y lógica dinámica.

---

## 🚀 Características del Proyecto

*   **Gestión de Productos:** Permite administrar el inventario de la tienda desde la consola.
*   **Lógica Dinámica:** Estructuras de datos optimizadas para el manejo de la información.
*   **Arquitectura Escalable:** Base sólida orientada al desarrollo de futuras APIs.

## 🛠️ Tecnologías Utilizadas

*   [Node.js](https://nodejs.org) - Entorno de ejecución para JavaScript.
*   JavaScript (ES6+) - Lógica del lado del servidor.

## 📦 Instalación y Uso

Sigue estos pasos para ejecutar el proyecto de forma local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Atxuris/pre-entrega-nodeJS.git
   ```

2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd pre-entrega-nodeJS
   ```

3. **Instalar las dependencias:**
   ```bash
   npm install
   ```

4. **Iniciar la aplicación:**
   ```bash
   npm start
   ```
